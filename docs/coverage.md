# Coverage

Every parameter of the reference analog model, in its raw units as the patch carries it (`core/params.inc`).
Columns: what the core implements; the law and where it was measured (fit error); whether the engine was
checked against the reference with it, and the result. A patch using anything marked "no", or a value
outside the implemented range, is reported by `vcore::notCovered()` (and `vcbench coverage`). Measurements
and analysis scripts: measurement runs va-core (2026-11-14) to va-round5 (outside this repository); the converter's
fitted tables (`core/laws.inc`). Acceptance against the reference: `docs/acceptance.md`.
